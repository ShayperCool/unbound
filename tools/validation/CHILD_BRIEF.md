measurements and tested bytes. New Native observations require two independent
complete matching captures before publishing one canonical reference. Preserve
all missing/extra/failing values and original tolerances. Unsupported behavior

Apply the user's insignificant-residual rule in PARITY_WORKFLOW.md. Small
invisible float/pixel differences that do not change game logic may be recorded
as nonblocking; never mask them or loosen a comparator. Systematic shifts, wrong
functional answers, order/lifetime changes and real bugs still need fixing.
Record each accepted residual in the receipt and docs ledger. Do not launch
Native captures or deep research just to eliminate it.

scripts use --kind build, CPU tools --kind tool. Do not nest leases. Never write
to another owner's target or frozen runtime. Background long commands, do useful
independent work, then use completion events/waits. No sleep/status polling by
the agent. Use tests/editor_runner.py for new or migrated Native runners.

CARGO_TARGET_DIR in the environment and no shared CARGO_BUILD_BUILD_DIR (see README,
Build isolation). Unchanged native source does not mean identical bytes; reuse
follows the actual artifact hashes.

Keep authorized independent implementation and review moving; a fixed count of
waiting packages alone does not stop the queue. Do not open ungranted work or
delegate again unless this task explicitly grants it. Complete the workflow's
short readiness check before costly validation; it grants no extra execution or
retry. Cosmetic nits do not need another full review; changed behavior, assertions,
fixtures or composition require the applicable new scoped review. Report a genuine
blocker once with the smallest needed evidence. Update the authoritative package
index; do not send repeated waiting/no-change updates or superseded requests.

Before final: finish/cancel searches and index clients, terminate only your own
leftover jobs, commit each logical step and ordinary-push when authorized.
Deliver one compact receipt: source, touched paths, commands/report links,
full artifact/input manifests, resolved/retained/introduced values, exact stub
