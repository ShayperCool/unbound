# Tracker modules probe (`audiotracker`)

Measures tracker module `AudioClip`s (`.mod`, `.xm`, `.s3m`, `.it`) in Editor Play mode on Unity 6000.0.71f1:

- **Asset import & metadata (`meta.*`)**: `channels`, `frequency`, `loadType`, `preloadAudioData`, `loadInBackground`, `ambisonic`, `loadState`, `samples` and `length` for ProTracker (`.mod`), FastTracker II (`.xm`), Scream Tracker 3 (`.s3m`) and Impulse Tracker (`.it`), plus `AudioImporter` variants (`CompressedInMemory`, `Streaming`, `forceToMono` + `sampleRateOverride`, `loadInBackground` + `preloadAudioData = false`, `compressionFormat = PCM`, and BPM 150 tempo control).
- **Synchronous background load (`lifecycle.bg_nopreload`)**: `LoadAudioData()` on a `loadInBackground` tracker clip loads synchronously to `AudioDataLoadState.Loaded` and logs Unity's warning that background loading of tracked music files is not supported.
- **Playback & controls (`play.*`, `ctrl.*`)**: signal presence, natural end, stereo channel separation, musical MIDI note per half (C5 left then G5 left + E5 right), duration and RMS across all four formats, BPM 150, importer variants, `loop`, `time` seek, `Pause`/`UnPause`/`Stop`, `pitch = 2` and `volume = 0.5`.
- **`GetData` / `SetData` (`data.*`)**: readback, mutation, and diagnostics across `DecompressOnLoad` (Vorbis and PCM settings), `CompressedInMemory` (`"Cannot set data on shared sample for audio clip \"...\""`) and `Streaming`.
- **`UnityWebRequestMultimedia.GetAudioClip` (`dl.*`)**: exact `AudioType` (`MOD`, `XM`, `S3M`, `IT`), `AudioType.UNKNOWN` auto-detection, mismatched types, invalid bytes, `DownloadHandlerAudioClip.compressed = true`, and `DownloadHandlerAudioClip.streamAudio = true` (rejected with `null` and Unity's tracker streaming error for both explicit tracker types and `UNKNOWN`).
- **`AudioSettings.Reset` (`reset.44100.*`)**: changing `outputSampleRate` to 44100 Hz leaves already-imported asset clips at their import-time sample rate (48000 Hz) while newly downloaded tracker clips decode at the new output sample rate (44100 Hz).

## Unity 6000.0 contract

- Manual *Audio files* (`https://docs.unity3d.com/6000.0/Documentation/Manual/AudioFiles.html`): Unity supports `.xm`, `.mod`, `.it`, and `.s3m` tracker module formats as `AudioClip`s.
- Scripting API `AudioType` (`MOD`, `XM`, `S3M`, `IT`, `UNKNOWN`), `AudioClip`, `DownloadHandlerAudioClip`, and `AudioSettings.Reset`.
- Measured behaviour specific to Unity 6000.0 (background-load synchronous warning, `CompressedInMemory` shared-sample `SetData` error, and `streamAudio` tracker rejection returning `null`) is gated on `Compat.TrackerAudioMeasured` (`ReleaseFamily.Unity6000_0`); other release families retain the unmeasured fallback.

## Usage

```bash
python3 tests/projects/audiotracker/run.py record --label run-a   # Editor, batch mode
python3 tests/projects/audiotracker/run.py publish run-a run-b
python3 tests/projects/audiotracker/run.py gate
```

The deterministic tracker fixtures under `Assets/Audio/` are generated by `make_assets.py`. Numeric values compare with `tolerance = 0.05` (playback durations and RMS); booleans, strings, MIDI notes, sample counts and channel counts compare strictly (`samples` differences exceed `0.05` and are listed explicitly).

## Known residuals (`residuals.json`)

23 of 103 values differ due to three synthesizer-level differences between Unity's FMOD tracker engine and Unbound's `libxmp-lite` decoder:

1. **Song length (+1 tracker tick, 19 `*.len` keys)**: Unity's FMOD reports 1 extra tracker tick (`rate * 5 / (2 * bpm)`: 93120 vs 92160 frames at 48 kHz / 125 BPM, 77600 vs 76800 at 48 kHz / 150 BPM, 85554 vs 84672 at 44.1 kHz / 125 BPM). `libxmp-lite` stops at the musical loop boundary so looped playback has no extra tail.
2. **IT mix-volume baseline (1 key, `play.tone.it.rms`)**: Unity's FMOD attenuates Impulse Tracker header mix volume 48 relative to 128 (RMS 0.10); `libxmp-lite` uses Impulse Tracker's baseline of 48 (RMS 0.26). Notes, panning and duration match.
3. **Compressed tracker download sentinel (3 keys, `dl.xm_compressed.{len,play,play.dur}`)**: with `compressed = true`, the Editor returns `samples = -1`, `length = 4294967.5` and plays without stopping naturally; Unbound still disallows `GetData` (`dl.xm_compressed.props` matches) while exposing the finite decoded length and stopping naturally.
